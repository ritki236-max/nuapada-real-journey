# Nuapada Real Journey — mission map

An offline, real-travel mission map of **Nuapada district, Odisha**.

Open the published site, choose your way of travelling (walking / running / cycling),
press **Start tracking** and physically travel to each place. When you really arrive,
that mission completes. There is no way to finish it by clicking — it is a real journey,
not an online game.

- 15 missions across the district (5 blocks + Jonk tehsil), ending back at Nuapada HQ.
- Live GPS position, track, speed, distance covered and ETA.
- A compass arrow always points to the next place.
- Works fully offline once the page is open (map engine and data are embedded).

Built by Sarvam AI. Map data (c) OpenStreetMap contributors (ODbL);
place data from GeoNames (CC BY 4.0).
